# IconForge command reference

The public command contract for the forge/hearth overhaul is in [CLI.md](CLI.md).
Start there for preferences, automatic application/icon lookup, explicit overrides,
refresh aliases, diagnostics, completion, and examples.

The unchanged execution-engine details are preserved in the
[v2.1.0 engine reference](LEGACY-USAGE.md). That is an archived reference: its
single-directory public CLI grammar is superseded by CLI.md. It remains useful
for image formats, recursive forge manifests, publication/rollback, native versus
internal application strategies, restoration, cache operations, and installation.

For the new CLI/backend boundary and future platform work, see
[ARCHITECTURE.md](ARCHITECTURE.md).
