# IconForge 2.3.0

IconForge 2.3 makes bulk application results actionable and improves diagnostics,
recovery, and application-matching performance. The existing forge/hearth CLI
and macOS backend remain in place.

## See which apps need attention

Bulk apply names unmatched icons, failed entries, and apps that need authorization
without requiring `--verbose`. It continues with other eligible applications after
an isolated failure and summarizes completed and unresolved entries separately.

```bash
iconforge apply --all --dry-run
iconforge apply --all --nuke
```

For a nonwritable app, IconForge prints read-only diagnostic facts and a scoped
native-helper command for that one app. It does not request or run administrator
authorization automatically. Review read-only-volume or locked-file errors before
choosing how to proceed. Run `iconforge nuke` as your normal user if a refresh is
needed after a separately authorized helper operation.

## Diagnostics and recovery

Errors retain underlying tool diagnostics and give affected paths and remedies
when known. Failed or interrupted runs, warnings, and unresolved entries retain a
private local diagnostic report and print its path. Reports may contain command
arguments and personal paths, so review them before sharing. Clean successful runs
remove their temporary reports.

Image publication remains transactional. If a rollback cannot complete,
IconForge retains recovery copies and reports their locations. Native writes now
check for a usable Finder icon resource rather than relying on the Finder flag
alone. When AppKit does not reveal a cause, IconForge reports that uncertainty.

## Faster matching

Application names are normalized once per discovery inventory and reused for bulk
matching. Exact and partial matching, duplicate-installation checks, and explicit
selection for ambiguous results retain their existing behavior.

## Upgrade

```bash
brew update
brew upgrade villagealchemist/iconforge/iconforge
iconforge --version
```

This is a source-only release. Homebrew builds the vendored Go processor and the
AppKit helper from the exact release commit. The application backend is macOS-only;
other platforms and a UI are future work. See the
[CLI guide](https://github.com/villagealchemist/iconforge/blob/v2.3.0/docs/CLI.md),
[architecture notes](https://github.com/villagealchemist/iconforge/blob/v2.3.0/docs/ARCHITECTURE.md),
and [changelog](https://github.com/villagealchemist/iconforge/blob/v2.3.0/CHANGELOG.md).
