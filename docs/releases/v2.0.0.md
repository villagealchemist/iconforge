# IconForge 2.0.0

IconForge 2 turns the original image-to-ICNS converter into one careful macOS icon workflow. The new command surface is
stateless and explicit: every run names the artwork, output, app, or `.icns` directory it should touch.

## A complete forge

PNG, JPEG, WebP, TIFF, and GIF sources are decoded and resized by IconForge's own Go processor. Each resulting ICNS
contains all ten standard and Retina representations and round-trips through the macOS iconset tooling.

Single-image, multi-image, and explicit recursive runs are supported. Recursive output mirrors the source tree and
preserves spaces and Unicode names. Every run builds a complete manifest before writing, checks collisions, stages the
entire result privately, and rolls publication back if a final replacement fails.

```bash
iconforge ./logo.png
iconforge forge ./artwork --recursive --output ./icons --dry-run
```

## Native app icons by default

Direct and bulk apply use IconForge's bundled Objective-C/AppKit helper. It sets Finder custom-icon state at the app
root without rewriting `Contents/` or replacing the application's code signature. A missing helper is treated as a
broken installation and never triggers a riskier fallback.

```bash
iconforge inspect "/Applications/Discord.app"
iconforge apply "/Applications/Discord.app" --icon ./Discord.icns --dry-run
iconforge apply "/Applications/Discord.app" --icon ./Discord.icns --nuke
```

For a disposable or locally controlled app with a traditional loose `.icns`, `--strategy internal-icns` remains an
explicit direct-only expert option. It preserves the first original icon, replaces the target, ad hoc re-signs the
bundle, verifies every architecture, and rolls back on failure. Asset-catalog apps are rejected.

## Explicit bulk apply

Bulk mode recursively discovers `.icns` files only below the directory supplied on that invocation. Filename stems are
matched to installed apps; exact matches are automatic, a unique partial can be confirmed once, and nothing is saved.

```bash
iconforge apply --all ./icons --dry-run --verbose
iconforge apply --all ./icons --nuke --verbose
```

Malformed icons, duplicate normalized keys, and two icons targeting the same app fail preflight before any app changes.
Unmatched and ambiguous entries are skipped and summarized. Bulk mode never mutates application contents or signs an
app.

## Source-built and inspectable

The release contains source, not prebuilt compiled binaries. Source installation and Homebrew build IconForge's Go
processor and native AppKit helper. Imported Go image packages are vendored with their license and patent notice, so
release builds do not need to resolve those packages over the network.

```bash
brew install villagealchemist/iconforge/iconforge
iconforge --version
```

CI verifies the source on pinned current Intel and Apple-silicon macOS runners. That matrix is evidence for those
environments rather than a promise about every macOS release.

## Start safely

- Read [`docs/USAGE.md`](../USAGE.md) for the complete interface and failure behavior.
- Begin application work with `inspect` and `--dry-run`.
- Use a disposable copied app for internal mutation tests.
- Elevate only a narrowly scoped native-helper operation when macOS requires authorization.
- Never run the entire CLI or Nuke as root.

✦ Good artwork deserves a proper icon. Now the whole path from pixels to Finder is part of the forge.
