# Make it at the forge. Keep it at the hearth.

IconForge turns artwork into complete `.icns` files, finds your applications,
applies their custom icons, and handles the requested cache refresh. Your
filesystem is yours: finished icons do not have to live beside your source art,
and they do not have to be generated by IconForge.

**This branch contains the unreleased CLI overhaul.** The latest Homebrew release
may not yet include these commands. No release or version bump is implied.

## ✦ Configure once, apply by name

```bash
iconforge config set the-forge "$HOME/icon-work"
iconforge config set the-hearth "$HOME/app-icons"
iconforge config show
```

`the-forge` is the default output destination. `the-hearth` is the finished ICNS
library for both single-app and bulk apply. They can be different folders or the
same folder. These are preference names, not directory names you have to adopt.

```text
app-icons/
├── Firefox.icns
├── Discord.icns
└── Visual Studio Code.icns
```

```bash
iconforge apply Firefox --dry-run
iconforge apply Firefox
iconforge apply Firefox nuke
iconforge apply --all --dry-run --verbose
```

Exact normalized app and icon matches are automatic. Ambiguous icons or duplicate
application installations are not decided by scan order. `--all` remains mandatory
for bulk application, and a requested bulk cache refresh runs once afterward.

## ♡ Keep control

```bash
iconforge forge ./artwork.png Firefox
iconforge ./artwork.png Firefox --output "$HOME/app-icons"
iconforge apply Firefox --from "$HOME/alternate-icons"
iconforge apply Firefox --icon ./experimental.icns
iconforge apply Firefox --app-root "/Volumes/Tools/Applications"
iconforge apply "/Volumes/Tools/Applications/Firefox.app"
iconforge restore Firefox
```

Explicit paths override defaults without rewriting them. Existing
`default-directory` configuration remains a fallback for either new preference
until that preference is separately set. `config unset` removes only its key.
Configuration stays data, never sourced shell code.

Supported artwork: PNG, JPEG, WebP, TIFF, and GIF. The existing Go processor,
transactional forge publication, and native helper remain in place.

## ⊹ Know what the tool will do

```bash
iconforge help apply
iconforge doctor
iconforge doctor Finder
iconforge capabilities
```

`doctor` is read-only. `capabilities` reports the current backend honestly:
macOS application icons are implemented; mobile and other platforms are not.
Finding a protected system application does not make its icon writable.

Shell completion is available without automatically editing your startup files:

```bash
# Zsh, after compinit
source <(iconforge completion zsh)

# Bash
source <(iconforge completion bash)
```

Fish is supported through `iconforge completion fish | source`.

## ▶ Install

Released version:

```bash
brew install villagealchemist/iconforge/iconforge
```

For this branch, use a macOS source checkout with Go and Xcode Command Line Tools:

```bash
make build
make test
make lint
make install
```

The Go dependencies remain vendored. This change introduces no additional runtime
binary or dependency. Installation still defaults to `~/.local`; alternate
prefixes are documented in the archived installation reference.

## ☾ Strategies and recovery

Native custom-icon application remains the default and leaves application
`Contents/` and its code signature untouched. It replaces a pre-existing Finder
custom icon without preserving that previous customization.

Internal replacement is still an explicit expert operation for suitable writable
loose-ICNS application bundles, never an automatic fallback or bulk strategy:

```bash
iconforge apply "/path/to/Disposable.app" \
  --icon ./replacement.icns --strategy internal-icns --dry-run
```

That strategy changes signed contents and uses ad hoc re-signing. Test it only on a
disposable copy first. `restore` cannot recover the developer's original signature.
App updates can remove customizations and internal backups. Do not run the entire
CLI as root; Nuke refuses to operate on root's caches.

`nuke` and `refresh` are aliases for the same existing current-user cache operation.
They do not disable SIP, Gatekeeper, or system-volume protection. This branch does
not remove bundled apps or implement special Finder Dock-icon replacement.
